# birthday

A romantic, interactive birthday celebration website created with endless devotion for Rumnaz Nurayeen.

## Features ✨
- **Canvas Fireworks Intro:** Dynamic illuminated letter reveal with elegant typography and starlight glow.
- **Photo Showcases:** Clean, frameless editorial portraits with floating romantic accents.
- **Virtual 3D Cake Ceremony:** Interactive candles that can be blown out with a wish and celebration confetti.
- **Living Meadow Garden:** Procedural blooming meadow with roses, tulips, daisies, sunflowers, and chimes.
- **Interactive Memory Gallery:** Romantic photo moments with heartfelt notes.
- **Celestial Constellation:** Galaxy star-linking interactive experience.
- **Love Letter Parchment:** 3D wax seal opening into a custom heartfelt love letter.

## Running Locally
```bash
node server.js
```
Open `http://localhost:3000` in your browser.
